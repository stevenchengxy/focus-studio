# Focus Studio for Mac 1.14.15

现在可以只调整某一个缩放镜头的跟随速度。在时间线选中缩放块，打开「跟随速度」，即可在 0.25×–2× 之间调整。需要恢复时，切回使用项目速度即可。项目速度仍在「动画」里设置。

新建和旧项目里的缩放片段默认继承项目速度。改动项目速度后，继承的片段会一起更新，单独设置的片段保留自己的倍速。预览和 MP4 导出应用相同的设置。

选好缩放片段后，可以直接告诉 Codex「把这段的跟随速度调到 0.5×」或「让这段恢复项目速度」。内置助手和外部 MCP 客户端都可以通过 `get_project.selected_zoom_id` 读取当前选择，再用 `update_zoom` 修改该段。

适用于 macOS 15 及以上，支持 Apple 芯片与 Intel。
