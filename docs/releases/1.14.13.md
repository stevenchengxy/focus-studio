# Focus Studio for Mac 1.14.13

- 改进缩放镜头对鼠标的跟随。指针在画面中央小幅移动时保持构图，快速移向边缘或折返时镜头会更早平移。预览和导出使用相同的轨迹与裁剪坐标。在「动画 → 跟随光标」里可调整强度，设为 0 可固定缩放目标。
- 在「鼠标 → 大小」中，指针可调到 0.5–8 倍，默认仍为 1.35 倍。Codex 可以通过 `update_settings` 的 `cursorScale` 设置相同范围。
- 在「设计 → 背景 → 图片」中新增 6 张离线背景，包括山峰、沙丘、海潮、纸艺、岩壁和雾林。内置图片共 18 张。

macOS 15 及以上，支持 Apple 芯片和 Intel。1.14.12 可在应用内下载并安装本次更新。此预览版尚未完成 Apple 公证。
