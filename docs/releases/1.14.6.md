# Focus Studio 1.14.6 preview

Mac 首次安装现在提供“安装并打开 / 更新并打开”引导。网页下载的副本会安装到“应用程序”，检测系统与个人应用目录里的旧版（包括改名副本），请求正常退出后替换，保留恢复备份，并切换到安装好的版本。拒绝降级、内容冲突和运行中替换；安装不删除项目、素材、设置或登录信息。

社区继续允许访客浏览。上传视频、AI 素材、保存上传草稿、编辑内容或发布前，必须使用 ChatGPT 登录，并在安装后的客户端完成一次确认：

1. Mac：打开 **设置 → 账户 → 社区发布**；Windows / Linux：打开编辑器顶部的 **社区发布**。
2. 点击连接 ChatGPT，在浏览器使用与社区相同的账户批准连接码。
3. 返回客户端，等到确认成功，再到社区发布页重新检查。

普通下载点击和仅批准连接码不会开通发布资格，必须完成客户端回连。社区连接与原有账户凭据分开；本地录制、剪辑和导出继续免费且无需登录。未确认客户端的作者仍可删除已有内容或取消发布。

Mac 包支持 macOS 15+，包含 Apple 芯片与 Intel 两种架构。Windows / Linux 配套客户端版本为 0.1.3。当前为预览版本：Mac 包采用本地签名，未经过 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”确认可信来源。请勿关闭系统安全保护。

安装、备份回滚、进程交接、社区权限及设备配对均有自动测试。完整干净 Mac 首装、真实旧版替换及各平台用户登录体验仍需现场验收；请在更新前完成录制并保存工作。
