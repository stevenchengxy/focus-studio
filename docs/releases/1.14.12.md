# Focus Studio for Mac 1.14.12 · Desktop 0.1.4

Mac、Windows 和 Linux 客户端支持在应用内下载更新，完成当前工作后选择「安装并重启」。安装前会验证发布签名和安装包。Mac 版从「Focus Studio → 检查更新」进入，Windows 和 Linux 从「帮助 → 检查更新」进入。

Mac 编辑器移除了视频字幕、字幕样式和 SRT 导出。打开旧项目后，预览和新导出的 MP4 会使用无字幕画面。章节仍可作为剪辑定位标记，麦克风录音和 AI 旁白可继续使用。首页、素材库和设置已精简重复的说明文字。

首次从 Mac 1.14.11、Desktop 0.1.3 或更早版本升级时，需要使用一次安装包。此 Mac 通用预览版适用于 macOS 15 及以上，尚未通过 Apple 公证。
