# Focus Studio 1.14.10 Preview — 更稳的光标，更从容的缩放

- 光标在停留时保持稳定，普通移动使用更直接的路线；点击位置与真实拖拽保持准确。修复长时间没有鼠标事件时，光标仍在缓慢漂移的问题。
- 消除箭头、手形和文本光标快速切换时的叠影。新项目默认使用清晰的自绘光标；已有项目保留所选外观。
- Zoom 跟随增加稳定区域，与既定缩放动画协调，减少反复拉动画面的情况。
- 默认放大 0.7 秒、完整停留 1.4 秒、缩回 0.8 秒。放慢过渡时保留阅读停留，短片按可用时长拟合。
- 在“动画”面板选择“应用舒缓节奏”，可更新旧项目的自动缩放并撤销；手动缩放可选择“自然”或“轻柔”调整入场与出场。
- 鼠标事件使用实际发生时间，减少系统繁忙时光标、点击反馈与画面不同步。预览、导出和 Codex MCP 共用相同算法。

保留应用内屏幕／窗口／区域选择器。

安装包适用于 macOS 15+，支持 Apple Silicon 和 Intel。仍为本地签名预览版，尚未通过 Apple 公证；更新保留已有项目和素材。
