# Focus Studio 1.14.3 preview / Desktop 0.1.1

## AI narration and captions (macOS)

- Configure MiniMax, OpenAI or an OpenAI-compatible speech endpoint independently of text and video models.
- Codex can inspect the selected speech model, submit a timed narration script, and add measured audio and matching captions to the current project through MCP.
- Before generation, Focus Studio displays the exact script, provider, model and voice for approval. Failed or overlapping generation does not partially modify the timeline. Provider billing is not automatically retried.
- Captions wrap across lines and are checked for fit before generation. Existing voiceover and audio-mixing controls remain available for refinement.

## Updates and downloads

- Mac and Windows/Linux desktop apps check for newer versions daily, with manual checking and preview/stable channels.
- Update notices wait for idle use. Installation is user initiated; project data and provider settings are stored separately.
- The website discovers published platform installers and displays the current version. Version-pinned downloads support resuming without switching file contents.
- Old releases without an update checker need one manual update from the website. Restart Codex's MCP connection after replacing the Mac app.

## Compatibility

- macOS 15 or newer, Apple Silicon and Intel. This preview is locally signed, not Apple-notarized.
- Windows x64 NSIS installer; Linux x64 AppImage and Debian package. Desktop 0.1.1 hosts Browser Studio and needs an internet connection. It does not include the native Mac editor/MCP service. Windows binaries are not Authenticode-signed.
- Speech adapters were tested with deterministic offline HTTP/audio fixtures. Live paid provider generation requires the user's configured API key and approval and is not claimed as verified by this release.
- Desktop installer builds and Electron smoke checks do not substitute for live microphone/screen-capture acceptance on each target OS.
