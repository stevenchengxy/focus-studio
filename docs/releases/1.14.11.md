# Focus Studio 1.14.11 Preview — 可关闭录屏背景

编辑器「设计 → 背景」提供 **无、纯色、渐变、图片** 四个选项。

- 选择「无」时，按裁剪后的原画比例输出，不添加背景图片、留白、圆角或阴影。
- 原有背景和画框设置会保留，切回后自动恢复。
- 背景选择移到设计面板顶部，只显示当前模式需要的选项。
- 预览、导出与 Codex MCP 使用相同规则。AI 可通过 `update_settings` 设置 `backgroundStyle: "none"`。

混剪中不同比例的素材保留完整内容，必要时使用黑边适配。此选项不提供透明通道 MP4。

安装包适用于 macOS 15+，支持 Apple Silicon 和 Intel。仍为本地签名预览版，尚未通过 Apple 公证；更新保留已有项目和素材。
