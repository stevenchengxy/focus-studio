# Focus Studio 1.14.8 preview

鼠标移动更稳定：已知没有按键按下的普通箭头轨迹会减少小幅绕行，保留点击时刻与位置、拖拽、文字选择和短暂停留。自动缩放的镜头加入中心静区，减少随鼠标细微运动而晃动；剪辑切点不继承上一镜头的惯性。预览与导出使用同一套算法，编辑器原有的“鼠标 → 平滑”设置继续有效，关闭平滑保留原始轨迹。

新录制保存按键状态；旧录屏没有该元数据时采用保守去抖，不会强行拉直可能的拖拽路径。

macOS 15.2 及更新版本的手动录制默认使用系统窗口/屏幕选择器。选定后可设置麦克风、系统声音和自动缩放，其余选项折叠。区域录制和 Codex MCP 直接选源保留原入口，macOS 15.0/15.1 保留兼容选择器。

系统整屏录制会在首帧前隐藏悬浮控制条，暂停、继续、截图和结束放在菜单栏。系统“停止共享”按正常结束保存，避免与应用“结束”同时发生时误判失败。

Mac **1.14.8（build 71）**，支持 macOS 15+，包含 Apple Silicon 和 Intel 架构。算法回归、录制状态回归、停止竞态测试、合成视频导出和两种架构的 MCP 握手验证通过。系统选择器的首次授权、真实整屏暂停恢复及系统停止共享仍待人工实机验收；这是一版预览更新。

安装包采用本地签名，尚未经过 Apple 公证。安装指引与校验信息随包提供。Windows/Linux 客户端本次不变。录制、剪辑和本地导出继续免费，第三方 AI 服务使用用户自己的凭据和额度。
