# Focus Studio 1.14.9 Preview — 恢复应用内选屏

恢复 Focus Studio 原来的录制选择界面：在应用内选择屏幕、窗口或区域，预览后开始录制。移除本次引入的 macOS 系统选屏入口，恢复区域重选及浮动录制控制条。

- 保留 1.14.8 的鼠标轨迹稳定、点击／拖动锚点和 Zoom 静区改进。
- 保留录制停止时的竞态修复，以及 Codex MCP 的选源、录制和编辑接口。
- 使用新版本号 1.14.9（build 72），让已安装 1.14.8 的用户能够收到更新。

安装包为 macOS 15+ Universal DMG，支持 Apple Silicon 和 Intel。本次仍为本地签名预览版，**尚未通过 Apple 公证**；正式版将在开发者会员和签名凭据就绪后单独发布。

安装更新不会移除已有项目或素材。

验证：完整 App 回归（选源／区域重选、倒计时、暂停恢复、MCP 导入／编辑／导出）、鼠标稳定性与权限测试、停止竞态测试均通过；两种架构的 MCP 握手与 DMG 校验通过。本机已从 1.14.8 升级并重新连接 MCP。本轮未重新执行首次权限或完整的真实录制验收。
