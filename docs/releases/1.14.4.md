# Focus Studio 1.14.4 · Open creation & community

Focus Studio recording, editing and export are currently free. The Mac app can export locally without signing in or contacting an entitlement service. Codex MCP export and composition follow the same policy. Paid third-party AI providers still use your configured key and their own usage charges.

The website now supports English and Simplified Chinese and introduces an optional sharing community. Sign in with ChatGPT, upload a finished video as a private draft, then choose whether to publish it. Public product demos can include a product introduction and link; AI footage has its own category. Published work is downloadable and reusable under the creator-confirmed CC BY 4.0 license. Authors can edit, unpublish or delete their uploaded copy. Local projects are never uploaded automatically.

Browser recording is no longer offered. Download the desktop app to record and edit. Windows/Linux Desktop Preview retains the hosted desktop editor inside its installed shell; initial loading still requires internet. Its rendering/export no longer requires account or entitlement requests. Mac retains the full native editor and MCP server.

Downloads:
- macOS 15+, Apple silicon and Intel: 1.14.4 build 66.
- Windows x64: Desktop Preview 0.1.2 installer.
- Linux x64: Desktop Preview 0.1.2 AppImage / Debian package.

Preview packages are not notarized/Authenticode-signed. Keep the normal installation security checks and follow the website's installation notes.

Validation: native app regressions, website TypeScript/build, backend and real workerd/D1/R2 integration tests, community HTTP lifecycle checks, desktop unit and sandboxed Electron smoke. The desktop smoke rendered twice and recovered a saved render without account/export service calls. Hardware recording on Windows/Linux remains a separate platform acceptance step.
