# Focus Studio 1.14.7 preview

首页和 AI 助手右上角新增常驻的 **设置** 入口，无需到 macOS 菜单栏查找。外观、语言、社区连接、ChatGPT / Codex、AI 模型与 MCP 工具集中在同一个设置窗口。

**社区连接** 现在显示当前账户和连接状态。点击“连接 ChatGPT”，在浏览器批准连接码，再返回客户端确认这台 Mac，即可使用社区发布功能。有效的旧版社区连接会自动迁移；社区连接与 Codex 登录分开管理。

首页和助手减少重复控件，按钮和卡片加入轻量反馈；连接状态切换采用短淡入动画，并遵循系统“减少动态效果”设置。配套网站简化连接引导，Mac 用户可直接打开客户端的社区设置。

Mac 版本为 **1.14.7（build 69）**，支持 macOS 15 或更新系统，安装包包含 Apple 芯片和 Intel 两种架构。本次沿用 1.14.6 的安装、备份与更新交接流程。Windows / Linux 配套客户端仍为 **0.1.3**，从 [v1.14.6-preview.1](https://github.com/stevenchengxy/focus-studio/releases/tag/v1.14.6-preview.1) 下载。

Mac 安装包采用本地签名，尚未经过 Apple 公证。首次打开请遵循安装包内的 `INSTALL.md`，保留正常系统安全检查。录制、剪辑和本地导出继续免费，无需社区登录；第三方 AI 服务仍使用用户自己的 API key 和服务额度。
