# Focus Studio for Mac 1.14.14

在编辑器「动画」中新增「跟随速度」。放大后镜头追随鼠标的速度可以从 0.25× 调到 2×。录制讲解时可以先试 0.5×，光标快速靠近画面边缘时仍有边缘保护。

新项目默认 0.75×。以前的项目以 1× 打开，调整后的速度随项目保存，并用于预览和导出。Codex 可通过 `update_settings` 设置 `zoomFollowSpeed`。

适用于 macOS 15 及以上，支持 Apple 芯片和 Intel。使用 1.14.12 或更新版本的用户可以在「Focus Studio → 检查更新」中下载并安装。此预览版尚未通过 Apple 公证。
