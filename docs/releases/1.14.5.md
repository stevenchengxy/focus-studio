# Focus Studio 1.14.5 · Glass identity & assistant refinement

The Mac app has a new lavender glass brand mark inspired by the Focus Studio website's aperture sculpture. The assistant conversation, activity presentation, composer and supporting controls receive a visual refinement, while recording, editing and export keep the existing local workflow.

The accompanying website update adds a dedicated community moderation interface and uses the same Focus Studio visual identity.

## Downloads and compatibility

- **Mac:** Focus Studio 1.14.5, build 67, for macOS 15 or later. The DMG and ZIP contain Universal 2 binaries for Apple silicon and Intel.
- **Windows and Linux:** Desktop Preview remains **0.1.2** in [v1.14.4-preview.1](https://github.com/stevenchengxy/focus-studio/releases/tag/v1.14.4-preview.1). This release does not rebuild those installers or claim full native editor/MCP parity with macOS. Their installed shell continues to use the hosted desktop editor and requires internet for initial loading.

These Mac packages use a local signature and **are not Apple-notarized**. Keep normal macOS security checks and follow the included `INSTALL.md` for first launch. Recording, editing and local export remain free; paid third-party AI providers retain their own keys and usage charges.

The Mac DMG, archived application, Universal 2 app/MCP helper, bundled resources, localization catalogs and SHA-256 package checksums were verified. The MCP helper answered stdio discovery for both available architecture slices. Binary/package verification does not substitute for a new Intel hardware acceptance test or Windows/Linux recording acceptance test.

Use the versioned `.sha256` file to verify both archives. Existing projects and media remain outside the application bundle.
