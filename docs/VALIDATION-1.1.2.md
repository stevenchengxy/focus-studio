# Focus Studio 1.1.2（build 4）验证记录

验证日期：2026-09-21。自动化运行环境：Apple Silicon，macOS 26.2。最低构建目标为 macOS 15.0。

## 录制后逐段编辑缩放

`swift run FocusStudioE2E --output-dir .artifacts/e2e-1.1.2` 通过。本次新增核心测试覆盖：

- 旧项目 JSON 未包含逐段速度或自动来源字段时，继续继承全局设置；新字段保存、重载无损。
- 开始、结束、总时长、完全放大后的停留时长、整体移动及恢复默认过渡；不会颠倒区间或超出视频边界。
- 每段的放大、缩回时间优先于全局设置，手动编辑后不会被重新生成自动缩放覆盖；原始自动片段不会悄悄重复出现。旧来源格式与移动后的手动片段均覆盖。
- 额外复现并修复合并输入片段在调整等待时间后重新出现的问题：输入发生于第 1 秒、第 3 秒，等待 5 秒时形成一个自动片段，手动缩短至 1.8 秒后将等待改为 0.4 秒，不会复活后半段。来源保存完整的点击 ID 与输入活动成员，并在重新分组前剔除已经被手动片段接管的事件。
- 反向合并、只接管第二个片段、混合点击与输入来源、成员 JSON 保存重载、旧项目未含成员字段的兼容全部覆盖；未被接管的事件仍可正常生成自动缩放，不因处于原区间内而被误删。
- 短于 0.05 秒的极短视频、零或负时长、零过渡、超长过渡、最大有限数及非有限输入；输出保持有限，过短片段仍能到达目标倍率。
- 压缩过渡后的停留时间编辑：一秒片段原有 2 秒 / 2 秒过渡，实际压缩到 0.5 秒 / 0.5 秒；把停留设为 2 秒后，总长为 3 秒，停留确实为 2 秒。
- 重叠片段、录入保持放大、点击反馈、裁剪、光标、背景和音频等既有媒体回归继续通过。

## 预览与真实 MP4 导出

测试将同一 2.4 秒合成录制分别保存、重新读取并导出为四份 960 × 540 MP4。四个版本的原始视频时长保持不变，只调整缩放区间与过渡参数：

| 版本 | 开始 / 结束 | 放大 / 缩回 | 完全放大停留 |
| --- | --- | --- | --- |
| 快速 | 0.25 / 2.125 秒 | 0.1 / 0.1 秒 | 1.675 秒 |
| 慢速 | 0.25 / 2.125 秒 | 0.8 / 0.8 秒 | 0.275 秒 |
| 短片段 | 0.25 / 1.25 秒 | 0.1 / 0.1 秒 | 0.8 秒 |
| 继承全局、舒缓曲线 | 0.25 / 2.125 秒 | 0.5 / 0.5 秒 | 0.875 秒 |

在每个版本的 7 个检查点对比预览与编码后画面，共 28 对，最大像素平均绝对差为 **0.901 / 255**，低于视频压缩容差 3。快速与慢速版本在 0.5 秒及 1.875 秒的画面差分别为 **14.054**、**14.046**；长短片段在 1.5 秒的差为 **27.184**。所有版本在结束后回到同一全景。继承全局的舒缓样式也按界面标注的精确秒数达到和离开峰值，没有隐藏时长倍率。

已查看四张自动生成的复核帧：快速进入比慢速进入更接近目标放大；延长后的片段仍放大时，缩短后的片段已回到全景。此项是确定性测试视频的真实导出，不是新录制的用户桌面视频。

证据位于 `.artifacts/e2e-1.1.2/`：

- `focus-studio-zoom-timing-report.json`：参数、逐帧对比及 `PASS` 状态。
- `focus-studio-zoom-timing-{fast,slow,brief,inherited-gentle}.mp4`：四份可播放的真实导出。
- `focus-studio-zoom-timing-{fast-entry,slow-entry,long-hold,short-return}.png`：已查看的复核帧。
- `focus-studio-e2e.mp4`：完整合成媒体回归，24 FPS，一条视频轨、一条音频轨，缩回后的像素平均差为 0.881。

最终重跑时，测试用的合成源生成器暴露了先写全部视频、再写音频导致的偶发 AVAssetWriter 背压等待。已仅在 E2E 工具中改为按时间交织提交音视频，并加入 15 秒 readiness 超时，防止测试无限等待；生产录制与导出代码没有因此修改。修正后完整 E2E（含新增来源成员拆分 / 合并测试）通过。

## 编辑器保存与导航

`zsh scripts/test-app-regression.sh --skip-build` 通过。测试连续通过真实 `editorBinding` 写入开始、结束、总时长、进入速度、退出速度、停留时长及整体移动；离开编辑器、刷新保存队列、重新读取项目后，仍为开始 **5 秒**、结束 **7.27 秒**、放大 **0.12 秒**、缩回 **0.65 秒**。

重新打开项目并修改全局自动停留后，手动片段及来源覆盖仍保留，原始点击处不重新产生缩放。既有权限前置检查、50 次打开 / 修改 / 返回、失效绑定读取与写入、异步保存也全部通过。

## 双语资源与安装包边界

`swift scripts/test-localization.swift` 通过：两种语言的 **497** 个键一致，格式参数占位符一致，录屏、麦克风及系统音频权限说明均存在。两种语言的 `Localizable.strings` 与 `InfoPlist.strings` 通过 `plutil -lint`。

安装包验证脚本对最终应用和 ZIP 解压副本内的资源执行以上检查，并检查原生 ICNS 与应用内 PNG 图标存在，结果均通过。构建与打包脚本通过 shell 语法检查。源码与资源摘要在两种架构编译期间保持一致。

Universal 2 的 `arm64` 和 `x86_64` 两个 release 切片均编译通过。最终应用与解压副本通过签名、macOS 15 最低版本、系统框架依赖、白名单静态资源、10 个音频素材及图标/双语资源检查；DMG 完整性校验通过。包内只有应用、安装说明、Applications 快捷方式及发布状态，不包含项目或凭据。

最终产物为 `dist/releases/Focus-Studio-1.1.2-universal-local.dmg`、同名 `.zip` 及 `.sha256`。最终应用可执行文件 SHA-256：`737435e842614702a276535fe61d0a1e10798838b4666dfa97227a034d408e78`。

当前机器没有有效签名证书，因此使用 ad-hoc 本地签名，未经过 Apple 公证。Intel 切片经过编译和结构检查，未在 Intel 实机执行；macOS 15 的兼容声明来自构建目标，实际验证环境为 macOS 26.2。打包结束后没有自动启动应用或操作用户界面。
