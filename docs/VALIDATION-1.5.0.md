## 结论与边界

- 全套 `zsh scripts/test.sh` 退出码 0；Universal 包和安装后的 app 验证通过。
- 真实 AI 网关模型的多轮聊天、共享上下文、计划草稿、取消执行，以及安装后聊天恢复，均在原生界面验证通过。
- Chrome 本地测试窗口录制成功，78.25 秒；预览移除了浏览器标签、地址栏、书签栏和系统菜单栏。计时递增，停止后正常进入编辑器；未自动添加音乐。
- **实录中的自动点击/打字缩放尚未通过实体输入验收。** 本次 CUA 输入改变了 Chrome 页面，但所有全局与本地 NSEvent 计数为 0，AX observer attachments 也为 0。权限预检均为 true、监听器均已注册；没有坐标越界、早于起点或焦点拒绝计数。事件没有进入采集器，不能宣称是 zoom 数学算法或权限失效。需要真实鼠标与键盘短录作对照；未重置 TCC、修改系统权限或采集文本内容。
- 未接入 Jev API、未向 TypeSafe 发送数据；Jev 调研及适用边界见 [JEV-RESEARCH.md](JEV-RESEARCH.md)。
- Intel 只完成交叉编译和包验证，未做 Intel 实机运行。没有 Developer ID 证书，发行包为 ad-hoc 本地签名、未经 Apple 公证；没有在线自动更新服务。

## 原生界面验收（截图先行）

### 1. 助手人物 — 通过

旧版是球形身体、光环与天线，不符合用户明确要求的“人的形象”。替换为原生 SceneKit 卡通人物：头发、耳朵、鼻子、嘴、紫色卫衣和手臂；保留呼吸、眨眼、说话、挥手和状态转换。无需外部图片下载。

截图：[旧助手](../.artifacts/qa-1.5.0/01-assistant-before.png) / [新助手](../.artifacts/qa-1.5.0/03-assistant-after.png)。

### 2. 聊天 → 草稿 → 确认 — 通过；自主点击能力有限

旧 Director 在已有网关模型可用时仍显示独立“未连接”规划页面，与助手割裂。现在共享同一会话，并保持右侧计划区域。

实测用已配置 `doubao-seed-2-0-pro-260215`，仅发送合成测试文字，无媒体附件：

1. 在独立助手窗口告知测试代号“紫色云朵”；回复确认。
2. 切换 Demo 导演追问；准确回答该代号，证明共享历史。
3. 请求 `https://example.com` 的等待 3 秒 → 滚动 200 → 等待 2 秒草稿；计划出现在右侧。
4. 点击 Run 出现确认，选择取消；未打开该网址、未录制，也未执行计划。
5. 安装并重启后，聊天和未执行草稿仍在。

截图：[旧导演](../.artifacts/qa-1.5.0/02-director-before.png) / [共享多轮聊天](../.artifacts/qa-1.5.0/04-director-shared-chat.png) / [草稿未执行](../.artifacts/qa-1.5.0/05-reviewed-plan-not-run.png)。

当前聊天不具备实时页面观察，因此代码拒绝模型猜坐标的 live-click 计划；截图演示中的点击仅用于缩放。不是完整视觉自主录制代理。Jev 的“观察—选择—核验—执行—验证”适合作为后续架构方向，不应描述为本轮已全部落地。

### 3. 安装 → 重启 — 通过

发现运行副本在 `dist/candidates/1.4.0`，默认 `dist/Focus Studio.app` 是 1.1.2。此前 `/Applications` 无正式副本。

在 1.5.0 候选应用内点击“安装设置”直接到安装页，显示版本/构建/路径；确认后成功复制至 `/Applications/Focus Studio.app`。随后主动退出空闲候选，启动正式路径，进程路径与二进制哈希匹配。原有 26 个项目不变，聊天恢复正常。没有删除或覆盖旧候选，不替用户修改 Dock。

截图：[安装成功](../.artifacts/qa-1.5.0/06-installed-success.png)。安装界面的异步刷新加入代次校验，避免旧快照覆盖新状态。

### 4. Chrome 实录 — 视频通过，实体输入待验证

使用仓库 [本地测试页](../Tests/Fixtures/recording-input-handoff.html)，独立 Chrome 窗口，不包含真实产品账号或网络请求。选择窗口与“仅网页内容”，手动触发 3 秒倒计时、录制、结束。随后将本次新增项目重命名为 `QA 1.5.0 — Chrome input capture`。

本次项目 ID：`9F79C7EF-64A2-4281-93A4-C85C8FD616AE`。保留该测试录制供排查，没有删除用户媒体。诊断文件位于其项目目录的 `interaction-diagnostics.json`。截图：[视频成功但事件计数为零](../.artifacts/qa-1.5.0/07-capture-no-events.png)。

浏览器专用自动化连接两次超时后，使用原生 Chrome UI 打开测试窗口；对控件的点击、逐键输入和坐标点击都没有进入全局事件监控。已经向用户请求一次实体鼠标/键盘短录，结果待补。
