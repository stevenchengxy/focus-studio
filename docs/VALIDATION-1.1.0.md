# Focus Studio 1.1.0 验证记录

验证环境：Apple Silicon，macOS 26.2。最低支持版本为 macOS 15。

## 返回崩溃

用户的实际崩溃报告指向 `FocusStudioApp.swift:62`：编辑器在项目被清空后仍读取强制解包的 Binding，触发 `Unexpectedly found nil while unwrapping an Optional value`。

修复采用带项目 ID 检查的快照绑定，拒绝已离开编辑器的过期写入，按顺序保存修改。预览离开时暂停并移除播放项与观察者，异步渲染、seek 的完成回调检查生命周期。

`scripts/test-app-regression.sh` 已通过 50 次循环，包含打开、改名、返回、返回后读取旧绑定、过期写入、切换另一个项目，以及最终修改落盘。测试使用独立临时项目库。

已在打包应用中实际测试播放中返回、修改点击样式后返回及重新打开，进程未退出，修改正常保存，未产生新的崩溃报告。

## 点击动画和视频渲染

正式 Core Image / AVFoundation 渲染管线通过以下检查：快速连续点击可同时显示、效果锚定点击位置、三种样式有不同画面、颜色参数生效、淡入淡出边界连续、旧项目兼容、新参数保存重载、预览与 MP4 一致（允许编码压缩差异）。

审阅文件：`.artifacts/e2e/focus-studio-click-feedback.mp4`、`.artifacts/e2e/focus-studio-click-feedback.png`。完整 E2E 还覆盖裁剪、缩放、区域坐标与音频。

## 输入期间保持缩放

新增采集测试验证聚焦输入框、鼠标移开后的稳定锚点、同应用不同窗口、区域边界、节流与单调时钟；数据结构只包含时间和坐标。完整 E2E 验证持续输入、暂停后缩回、切换输入框、没有前置点击、排除裁剪外的地址栏、旧项目解码、手动区块与普通动画滑块调整的兼容。

`.artifacts/e2e/focus-studio-typing-focus.mp4` 为通过正式导出管线生成的 7 秒 H.264 测试视频（960×540、24 fps）。3 秒帧仍保持放大，6.2 秒帧恢复全景。默认输入结束等待 1.4 秒，编辑器可调 0.4–5 秒。

最终通用安装包在本机实际录制了独立 Chrome 测试窗口：手动开始 → 倒计时 → 25 秒录制 → 完成 → 编辑器 → 播放中返回均正常。录制画面正确去除了浏览器标签栏、地址栏及书签栏，没有自动添加音频或打开权限设置。

**实录边界**：该构建运行时报告 Input Monitoring 与 Accessibility 未授权，因此此次实录的点击与输入事件为空；已请求用户手动授权，Chrome 外部输入活动的完整实机验收仍待授权后进行。不得把确定性采集/渲染测试等同于此项实机验收。测试项目保留为 `QA - Chrome typing capture (permissions pending)`。

## Codex 配置

`scripts/test-codex-connection.sh` 使用隔离偏好和 JSONL 模拟服务验证首次登录、独立 Keychain 配置、已有账号只读连接、模型分页与选择、无效路径和模型恢复。还覆盖登录响应与完成通知同批到达、快速完成的规划、重复发送、规划开始前取消和断开连接竞态。模拟测试不会创建真实登录或产生模型调用。

`scripts/test-codex-connection.sh --live-read-only` 已与本机官方 Codex 实际连接，读取到 5 个可用模型；没有修改认证状态或发送模型请求。

另外在真实应用中验证了新用户独立配置显示登录提示、手动选择已有 Codex 登录后连接成功。发送一条不包含网页或个人数据的 5 秒截图演示规划请求，成功得到结构化计划；未执行计划，也未修改已有认证。

## 分发范围

安装包仅包含应用、静态素材、安装说明和发布状态；不包含开发机器上的项目、账号或登录文件。分发校验会检查两个架构、最低 macOS 版本、系统动态库依赖、签名和素材完整性，并再次检查解压出的应用。

当前环境没有有效 Developer ID 证书。`local` 包采用本地签名，未经过 Apple 公证；首次打开可能需要用户在系统设置中允许。Intel 和 macOS 15 实机不在当前验证环境中，不能以交叉编译替代实机验收。

最终打包包含输入保持缩放与 Codex 设置同步修复；应用可执行文件 SHA-256：`f118dd553427abcab50fc9e0e1dd4b7d4842c9c305f0b79577019c9fd772f5d8`。DMG、ZIP 和 SHA-256 清单位于 `dist/releases/`。
