# 经典演示特效与账户导出

此文对应 1.13.0 / build 61 的实现。网站入口为 [Focus Studio](https://focus-studio.stevenchengxy19.chatgpt.site/)，登录和套餐入口为[账户页面](https://focus-studio.stevenchengxy19.chatgpt.site/account)。

## 局部强调

暂停到需要强调的画面，在「局部强调」轨道点 **＋**，框选区域并确认，再在右侧选择效果。选区使用原始素材坐标，适用于录屏、导入视频与图片。

| 效果 | 用途 | 可调参数 |
| --- | --- | --- |
| 聚光 | 保持细节清晰，弱化周围内容 | 背景、强度 |
| 卡片浮起 | 将选区独立放大 | 倍率 |
| 倾斜揭示 | 二维倾斜入场，随后回正 | 倍率、入场时长 |
| 透视卡片 | 将选区投影成有景深变化的倾斜平面 | 倍率、透视角度 −35°～35° |
| 放大镜 | 在选区中央显示圆形放大镜 | 倍率、镜片边框宽度 |
| 描边强调 | 沿选区边缘逐渐画出轮廓 | 描边宽度、入场时长 |

背景可选压暗、模糊或不处理；效果均支持持续时间、入场与退场。角度和描边宽度放在「高级」中。倍率范围为 1～3，边框为 1～12 像素，以 1080 像素的源画面高度为参考随画面缩放。

独立效果轨道支持移动、调整两端、禁用、复制、删除、撤销与重做。效果绑定原片段及源时间；裁短后再拉长可恢复被隐藏的效果范围。启用的局部效果不能重叠。

Codex 与应用内助手使用相同的 `add_region_effect`、`update_region_effect`、`delete_region_effect`。先用 `capture_frame(source_frame: true)` 查看原画面，再传入 `clip_id`、输出时间与归一化选区坐标。新增预设为 `perspective`、`magnify`、`outline`；可选参数为 `perspective_degrees` 与 `outline_width`。操作流程见 [MCP 技能](../skills/focus-studio-mcp/SKILL.md)。

## 登录与套餐

1. 打开「设置 → 账户」，选择「前往浏览器登录」。
2. 在网页使用当前可用的登录方式登录，核对设备配对码并明确批准连接。
3. 回到应用，账户页会显示免费次数或订阅状态。

Focus Studio 账户与 Codex 登录分开管理。前者用于导出额度与订阅，后者用于驱动助手。设备令牌保存在 macOS Keychain，退出账户会尝试撤销当前设备并删除本机令牌。

每个新账户包含 **一次成功导出**。之后可选择 **$29 / 月**，或 **$108 / 年，相当于 $9 / 月**。录制、编辑与帧预览不消耗次数。编辑器、内置助手、外部 MCP 和视频拼接共用同一账户额度；失败或取消的渲染不消耗免费次数。

导出需要在线验证。当前可通过 ChatGPT Sites 登录、配对桌面端并使用免费额度，无需先配置 Google 或 Stripe。Google 是可选登录方式；付费订阅须在服务端配置 Stripe 后开放。账户数据库与服务须正常运行；服务不可用时应用会提示重试，不会伪造登录、订阅或免费额度。配置步骤及所需密钥见[账户和付款部署文档](../website/docs/billing-and-accounts.md)。媒体继续在本地渲染，额度接口发送账户、项目与导出任务标识，不上传录屏内容。

## 中断后的导出恢复

应用先预约额度，在完整 MP4 已渲染到临时文件后才提交额度，最后发布到用户选择的位置。提交前会写入本机恢复记录。

如果服务器已扣除额度，但网络丢失了响应，应用会保留完成的视频和恢复记录。打开「设置 → 账户 → 恢复导出」，使用原账户并选择保存位置。恢复会确认**同一笔导出授权**，不会重新申请免费次数。成功保存后删除恢复记录。提交确认后若文件移动失败，也会保留完成的视频以供恢复。

恢复依赖原临时文件仍然存在；不要在恢复前手动清理它。恢复记录位于 `~/Library/Application Support/FocusStudio/ExportRecovery/`，不包含登录令牌。

## 验证与边界

本地验证已通过：

- 9 个真实 MP4 变体，覆盖全部六种预设、裁剪/缩放、导入视频与图片；预览和导出最大平均像素差为 1.009 / 255，效果前后恢复原画面。
- 参数持久化、源时间绑定、边缘透视卡片约束、零背景强度与旧项目兼容。
- 完整助手测试：额度拒绝、取消、失败、提交拒绝保护原文件，以及真实 MP4 的响应丢失和同一授权恢复。
- 完整应用回归、真实 MCP helper 导出调用、本地化 1367 项与技能校验。
- build 61 定向回归：只有同一任务的 `committed` 回执允许发布视频；损坏、不匹配或未提交的回执保持可恢复状态。

相关日志为 `.artifacts/classic-effects-e2e.log`、`.artifacts/account-native-assistant-final.log`、`.artifacts/account-native-app-final.log`、`.artifacts/account-commit-receipt-test.log`。账户测试使用隔离服务替身；这些测试不等同于真实 Google 登录或 Stripe 付款验收。

当前为固定选区，选区内视频继续播放；圆形放大镜取框选区域中央可容纳的圆形。尚不支持对象跟踪、定格、任意形状遮罩或完整 AE 合成工作流。透视卡片是原始像素的平面投影，不是可编辑的三维场景。背景模糊用于强调，不是隐私遮挡。手动录制的点击检测与自动缩放算法未作修改。离线帧提取测试不代表界面帧率承诺。
