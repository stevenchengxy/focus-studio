# Focus Studio 1.2 设计与实施计划（2026-09-21）

本文记录 1.2 版本六项需求的现状分析、方案取舍与验收标准。实施顺序与本文一致；每一节都有"验证"小节，对应 `scripts/test.sh` 或实机检查。

## 0. 现状

- 原生 SwiftUI + ScreenCaptureKit 应用，SwiftPM 构建，macOS 15+。
- 1.1.3 已具备 Codex Director、自动缩放、音频 finishing、双语界面。
- 仓库此前不是 git 仓库；已在本机初始化并推送到 GitHub `stevenchengxy/focus-studio`（public）。

## 1. Codex 登录与配置

### 根因

本机同时存在两个 Codex 可执行文件：

| 路径 | 版本 | 说明 |
| --- | --- | --- |
| `/opt/homebrew/bin/codex` | 0.42.0 | PATH 中靠前，`CodexExecutableDiscovery` 优先命中 |
| `/Applications/ChatGPT.app/Contents/Resources/codex` | 0.155.0-alpha.9.2 | ChatGPT 桌面应用内置，用户日常使用 |

用户的 `~/.codex/config.toml` 由新版写入（`model_reasoning_effort = "ultra"`），旧版 0.42.0 无法解析，`codex app-server` 直接退出。应用只显示 "app-server exited with status 1"，stderr 被丢弃，用户无从定位。`scripts/test-codex-connection.sh --live-read-only` 复现失败；改用 ChatGPT.app 内置 codex 后通过（5 个模型）。

### 方案

1. **按版本择优**：`CodexExecutableDiscovery` 枚举所有候选，执行 `codex --version` 取版本号，选择最高版本；显式路径仍然优先。版本探测有超时，失败的候选视为 0.0.0。
2. **可见的诊断**：app-server 在握手完成前退出时，把 stderr 的最后几行（去除任何形如 `sk-`/`Bearer`/`apiKey` 的片段）作为错误说明展示，例如 "Error loading configuration: unknown variant `ultra`"。
3. **连接向导**：Connection 面板显示"检测到的安装"列表（路径、版本、推荐标记），一键选择；状态区给出下一步（登录 / 选模型 / 修复配置）。
4. **测试**：fake-codex 支持 `--version`；新增"多候选择优"与"退出诊断"的用例；保留现有 13 个协议用例。

### 验证

`bash scripts/test-codex-connection.sh` 与 `--live-read-only` 均通过；实机在 Connection 面板看到 ChatGPT.app 内置版本被自动选中。

## 2. 使用感受与动画

- 页面切换（项目库 / 录制选择 / 倒计时 / 录制中 / 编辑器）使用统一的 `StudioTransition`：淡入 + 轻微位移，`.easeOut(0.28)`。
- 录制源卡片：选中态用 `withAnimation(.spring(response: 0.32, dampingFraction: 0.82))`，悬停抬升与描边。
- 项目库卡片：真实首帧缩略图（`AVAssetImageGenerator`，缓存到项目目录 `poster.jpg`），悬停抬升。
- 编辑器工具栏 / 检查器切换：内容以 `.transition(.opacity.combined(with: .move(edge: .trailing)))` 切换；时间线 Zoom 块选中态动画。
- 倒计时数字使用 `contentTransition(.numericText())` 与脉冲圆环。
- 所有动画尊重"减少动态效果"系统设置（`accessibilityReduceMotion`）。

### 验证

实机截图；构建无警告；`FocusStudioAppRegression` 通过。

## 3. 录制源实时预览

- 新增 `SourcePreviewProvider`（Capture 模块）：对当前可见的 display/window 卡片用 `SCScreenshotManager` 以 320 px 宽逐个刷新（实测 10 个窗口一轮约 450 ms），刷新周期 1 s，卡片离屏即停止。
- 选中卡片用低分辨率 `SCStream`（约 12 fps）实时预览；区域模式显示所选显示器缩略图并叠加已选区域框。
- 缩略图仅存在内存，不落盘；离开录制页立即释放。

### 验证

实机：切换窗口内容后 1 s 内卡片更新；选中卡片连续更新；返回项目库后 CPU 回落。

## 4. 缩放丝滑度、特效与音乐

### 缩放

1. **Cinematic 曲线**：新增 `ScreenAnimationStyle.cinematic`，采用临界阻尼弹簧的闭式解 `1 - (1 + ωt)e^{-ωt}`，位置、速度、加速度连续且无过冲；按 easeIn/easeOut 时长求 ω，使 98% 到位。作为新项目默认值。
2. **连续点击 pan 链接**：`TimelineMath.generateZoomSegments` 引入 `zoomChainGap`（默认 1.0 s）：下一次点击若落在上一段结束后 1 s 内，则延长上一段使两段重叠，相机保持放大并平滑 pan，不再"缩回再放大"。
3. **焦点插值**：焦点 handoff 改为使用与缩放相同的曲线，pan 略先于 scale（时间偏移 8%），符合真实镜头运镜。
4. **运动模糊**：`CIZoomBlur` 中心改为缩放焦点在画布上的位置（此前固定为画面中心），并按 pan 速度叠加方向性 `CIMotionBlur`。
5. 单元测试：曲线在 t=0/1 处一阶、二阶导为 0；链接后 handoff 时刻 scale 不低于 0.95×目标；旧项目解码不变。

### 特效与音乐

- 调研：OpenScreen（CC0 曲库 + 哈希锁定）、FollowCursor（活动分段与 pan 链接）、Screenize（弹簧相机）、Cursorfly（点击感知）。本版本采纳"pan 链接"和"临界阻尼相机"，其余记录在 `docs/REFERENCE_RESEARCH.md`。
- 新增 CC0 曲目（OpenGameArt 作者页明确标注 CC0，SHA-256 写入 `catalog.json`，构建脚本校验）。
- 新增 Spotlight 聚焦效果（可选）：缩放期间对焦点外区域轻微压暗，强调操作区域。

## 6. AI 视频/生图 SKILLS（火山引擎 Ark）

- 目录 `skills/`，Claude Code SKILL.md 格式，可通过 `--add-dir` 或复制到 `.claude/skills` 使用。
- `ark-video-clip`：Seedance（2.0 / 2.0-fast / 2.0-mini / 2.5 / 1.0-pro）文生视频、图生视频（首帧/尾帧/参考图），任务轮询与下载，成本预估。
- `ark-still-image`：Seedream（5.0 / 5.0-pro / 4.5 / 4.0）标题卡、产品主视觉、背景；支持以录屏截图为参考图做风格化。
- `demo-storyboard`：把产品描述 + Focus Studio `project.json`（点击、缩放时间）转为分镜 JSON（片段、提示词、时长、转场、字幕）。
- `product-demo-composer`：ffmpeg 合成：AI 片头 → Focus Studio 导出 → 章节字幕 → AI 片尾，xfade 转场、BGM ducking、1080p/4K 输出；产物可再导入 Focus Studio 编辑。
- 共享 `scripts/ark_client.py`：只从环境变量 / `~/.config/focus-studio/ark.env` 读取密钥；输出缓存按提示词哈希命名，避免重复计费。
- 验收：一次 Seedream 生图与一次短时长低分辨率 Seedance 生成真实通过；合成脚本用 E2E 合成视频跑通。
