# 用 Codex 录制并剪辑产品演示

在 Focus Studio 的 **AI 助手** 中直接描述完整目标，例如：

> 录制 https://finlyze.ai/dashboard 的 AI 助手新对话：输入“请用一句话介绍 Finlyze 的 AI 助手功能”，发送一次，完整回答显示后保留约 8 秒阅读。录完保留原片，创建目标 25–30 秒的精剪副本，剪掉明确空等，保留输入和发送，把重点镜头保持 3 秒左右。检查切口和结果画面后导出 1920×1080、30 帧。

选择 Codex 且已完成其登录后，发送请求会自动连接。助手会准备网页，展示一次包含窗口、目标、输入能力和时长上限的任务卡。点击“开始演示”后才检查页面并开始录制。登录需要先由使用者完成。录制中的光标、点击和缩放来自同一份操作轨迹；外部工具自己发送的、没有通过录制工具上报的动作不会凭空出现在轨迹里。

录制完成后会自动保存并回到编辑器；如果同一句请求已包含剪辑和导出，助手会继续完成，无需再发一次请求。

编辑器里的 **精剪当前视频** 会把剪辑请求填入同一个会话，可修改后发送。也可以继续说：“把第二段缩放延长到 6.5 秒结束”“这个回答要保留完整”“只预览，暂不导出”。

## 剪辑如何进行

1. `analyze_demo_pacing` 从输入轨迹提出候选等待区间，不修改项目。没有动作不等于画面没有内容；有源音频或缺少动作证据时，默认保留整段。
2. Codex 查看候选切口和结果画面，确定保留区间。
3. `create_demo_cut` 可根据审阅后的保留区间快速生成独立剪辑项目。需要逐镜头调整时，先用 `get_timeline` 读取当前片段 ID，再用 `split_clip`、`trim_clip`、`delete_clip`、`move_clip` 编辑。第一次片段操作创建一个工作副本，后续操作继续修改这个副本；原始项目保留。所有操作同时重排视频、声音、光标、点击、输入、缩放和章节。
4. 在视频轨道的两个片段之间，用 `set_transition` 设置硬切、淡黑或闪白，并指定 0.1–2 秒的效果长度。`set_clip_audio` 独立调整一个片段的原声（0 为静音，1 为原音量，最高 2）；背景音乐和点击音效仍在音频面板调整。预览与导出使用同一效果配置。
5. `update_zoom` 按每段稳定编号调整起止时间、目标、倍率与缓动。结构性剪辑后重新读取项目和片段 ID，之后的预览、修改和导出都使用新项目的新时间轴。
6. 检查开场、切口、重点操作和结尾，再用 `export_project` 导出。修改后可用相同时间和尺寸重新预览，画面会重新渲染；剪辑仍可在软件中手动继续调整。

阅读镜头可指定：“末尾回答保持 8 秒，镜头固定在回答处，不跟随旧的发送按钮位置。”也可以继续说：“预览 25 秒，把阅读缩放调为 1.45 倍，再预览同一秒，确认后导出新文件。”

在编辑器选择 **视频**，可以在滑轨上选择片段、拖动边缘裁剪、拖动片段排序，或在播放头按 `S` 拆分。片段右键菜单提供拆分、左右移动与删除；片段之间的小图标用于选择转场。时间轴的加减按钮可放大到接近逐帧检查，横向滚动时左侧轨道名称保持可见；“适合窗口”可快速看回全片。右侧检查器可精确输入入点/出点、调整原声、删除片段；图片片段可单独延长或缩短。`⌘Z` 撤销、`⇧⌘Z` 重做，空格播放/暂停，左右箭头逐帧移动。裁剪在原始素材上无损进行：片段的入点/出点是**其对应源视频的时间**，播放头和缩放使用**剪辑后时间轴的时间**。软件保存的是可继续编辑的项目；导出才生成最终 MP4。

首页的**通用素材库**保存本机导入的视频和图片，也接收 AI 生成的素材。每个剪辑项目另有自己的素材库：从通用库选中素材并明确加入当前项目后，才会复制进项目；加入项目本身不会把素材放上时间轴。随后可在编辑器中将素材拖到视频轨道，或让 Codex 用 `list_media_assets`、`insert_media_asset` 放置。直接从编辑器导入本机素材仍只加入当前项目。第一次编辑原录屏会创建独立工作副本，原片保留。

你可以让 AI 助手“为这段录屏生成一个 5 秒的产品空景，并放入通用素材库”。助手先交流用途和画面要求；调用 Seedance 视频或 Seedream 图片生成前会展示费用确认，成功后放入通用库。生成不会擅自改动已有剪辑。没有付费生成需求时，直接导入已有素材即可。助手等待模型答复时会显示“思考中”和当前执行状态。会话可新建、切换、重命名、删除和从历史中检索。

首页“更多”里的**截图转视频**把一张 PNG/JPEG 截图做成约 12 秒、可继续编辑的静态片段；之后可以手动添加推拉缩放。它适合缺少操作过程的产品画面，录屏或导入视频的主流程无需使用。

逐镜头编辑最多 128 个片段，片段至少保留 0.1 秒。目前转场是硬切、淡黑与闪白，不提供跨片段叠化、任意变速、光流补帧或自动识别语音/画面静止。生成答案和加载动画要通过预览判断，不能仅依赖鼠标时间戳裁掉。

## 从外部 Codex 使用

先在 Focus Studio 连接设置中连接外部 Codex，再安装本仓库的技能：

```sh
bash skills/install.sh --codex --skill focus-demo-editing
```

该命令也安装必需的 `focus-studio-mcp`。在新 Codex 会话中使用 `$focus-demo-editing`，给出项目或完整录制目标即可。完整流程与检查项见 [剪辑 Skill](../skills/focus-demo-editing/SKILL.md)。

这条流程已在 Finlyze 实测：build 39 一次请求完成录制、输入、发送、精剪及初次导出；build 40 在同一项目完成重复预览、阅读镜头调整、最终导出和正常回复。成片 29.6 秒，原片保留，详情见[验证记录](validation/2026-09-28-unified-assistant.md)。

手动录制原有鼠标追踪算法保持不变。
