# Build 52 media and timeline checkpoint (2026-09-30)

Build 52 adds shared-media management on the home screen, improves timeline scrolling and fine-frame zoom, separates transition controls from clip trim handles, and exposes separate outgoing/incoming transition timing and curves in the editor and `set_transition` MCP tool. Existing transitions still decode with their original even split and linear curve. Switching between fade and flash preserves custom timing. No manual recording or mouse-tracking algorithm changed.

## Validation

- `swift build --product FocusStudio`, `swift build`, `zsh scripts/test-ai-assistant.sh --skip-build`, `zsh scripts/test-app-regression.sh --skip-build`, `swift scripts/test-localization.swift`, and `git diff --check` passed. Focused tests cover legacy transition JSON, asymmetric effects, invalid overlap/parameters, cut survival, MCP receipts, shared-media Trash recovery, and independent project copies.
- `FOCUS_STUDIO_ARCHS=arm64 zsh scripts/build-app.sh --install` built, signed, verified, and installed Focus Studio 1.12.0 (52). The bundled MCP helper negotiated protocol `2025-11-25` and listed 46 tools. This is an arm64 ad-hoc local build, not a universal notarized release.
- In the installed app, the home library showed **Manage**, item actions, selected count, a Trash button, and a confirmation explaining that project-owned copies remain. The confirmation was cancelled, so the user's shared media was preserved.
- In the installed editor, a 21.6-second take was zoomed to 400% and scrolled to the middle and near the end. Ruler labels, cursor track, and filmstrip images stayed visible at both positions. The first installed candidate exposed a blank ruler/filmstrip after scrolling; replacing preference-based offset tracking with `onScrollGeometryChange` fixed the observed regression before build 52.
- In an existing two-clip project, the transition menu was visibly above the video clips while both trim handles remained on the clip edges. The inspector exposed separate Exit, Entrance, Exit curve, and Entry curve controls. The project was inspected without changing its content.
- A live Codex MCP `get_status` returned build 52, idle recording and the open editor. `get_timeline` returned two clips and the transition's `outgoing_duration`, `incoming_duration`, `outgoing_curve`, and `incoming_curve` fields.

Native checks establish that the tested interactions and controls work at the sampled positions. They are not an instrumented frame-rate benchmark or a manual trim-drag study; [issue #8](https://github.com/stevenchengxy/focus-studio/issues/8) remains open for a measured long-timeline performance baseline.
