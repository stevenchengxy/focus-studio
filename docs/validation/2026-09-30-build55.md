## Remaining limits

- Passive mouse-hover scrubbing was implemented with frame-quantized, rate-limited seeks. The available desktop automation can click and drag but cannot move a pointer with the button up, so that exact hover gesture was not verified in native UI automation.
- Re-extending a clip restores source frames and source audio. Trimmed-away click, cursor, interaction, zoom, and chapter metadata are not retained for later restoration in an existing saved project. See [issue #25](https://github.com/stevenchengxy/focus-studio/issues/25).
- The drag path now updates a local preview and commits one project change on release; project saves coalesce rapid snapshots. This reduces expensive work per pointer event, but no instrumented frame-rate measurement was made. The long-timeline performance follow-up remains [issue #8](https://github.com/stevenchengxy/focus-studio/issues/8).
