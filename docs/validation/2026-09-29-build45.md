# Build 45 integrated validation — 2026-09-29

Base: `f992a9e` from `origin/main`. The source and the locally installed app are Focus Studio 1.12.0 build 45. This is an ad-hoc signed arm64 development build, not a notarized Universal 2 release.

## Result

The complete `zsh scripts/test.sh` suite passed (local log `.artifacts/full-suite-build45-final.log`). It covers capture permissions, pause/resume and audio continuity, E2E rendering, English/Chinese catalogs, app lifecycle and editor regressions, toolbar snapshots, installation, Codex planning/connection, the AI gateway and assistant, and the MCP protocol/forwarder. The assistant tests were run again after a test-only Swift 6 isolation warning fix and passed (`.artifacts/shared-media-actor-isolation-tests.log`).

The new renderer tests first reproduced missing zooms on imported media and a sideways portrait export. They then compared actual preview and exported MP4 pixels for zoomed PNG and H.264 assets, a 90° `preferredTransform` clip, and an original recording with orientation metadata. The portrait output is 360×640 with its red/white markers vertically ordered. The preview/export paths share the same renderer. The physical-mouse recording algorithm was not changed.

The app regression imported nine test media items into isolated storage and confirmed that the newest appears first on the home screen. It also covered shared-library persistence, explicit copy into a project, clip insertion, Undo/Redo, original-source integrity, assistant history and scroll behavior, recording lifecycle, and an MCP end-to-end import/edit/export fixture. Separate assistant tests refused export/assembly into the shared media directory, including index metadata and symlink paths, with file bytes unchanged; consecutive redo calls in one assistant request restored two edit-history entries.

`FOCUS_STUDIO_ARCHS=native zsh scripts/build-app.sh` passed production build, ad-hoc signing, bundle verification, 1,198 matching localization keys, and stdio negotiation of 46 bundled MCP tools. The normal installer updated `/Applications/Focus Studio.app` from build 44 to 45 and verified the copy. The installed home screen displayed the shared catalog and existing projects; its “More” menu displayed **截图转视频**, correctly describing the 12-second editable still-image clip. Existing projects and credentials were left in place.

The real Codex CLI 0.158 successfully invoked `focus-studio/get_status` against an isolated app host in the connection test. On this machine `codex mcp list` shows `focus-studio` enabled and pointing to the installed build 45 helper. The installed helper itself passes the full MCP handshake/catalog tests. A live call from external Codex into the installed app still requires the app's first-use persistent approval; no approval was granted during this validation.

The existing local Finlyze demo at `.artifacts/finlyze-demo/Finlyze-Product-Demo-1080p.mp4` remains a 29.6-second H.264 1920×1080/30 fps file and passes full FFmpeg decoding. This final build was not used to make a new Finlyze recording; the earlier recording and editing receipts are in [the unified assistant validation](2026-09-28-unified-assistant.md).
