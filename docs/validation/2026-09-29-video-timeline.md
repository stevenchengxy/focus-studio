The native editor and Codex tools now operate on the same non-destructive clip timeline. The first edit creates a separate working project with its own byte-identical source movie. Further splits, inward trims, deletes, reorders, transition choices and clip-source-audio changes update that project in place. The unedited project remains in the library.
